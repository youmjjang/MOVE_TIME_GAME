# MOVE = TIME — 10 STAGES

브라우저에서 실행되는 10스테이지 미니게임입니다.

- 공개 게임: https://youmjjang.github.io/MOVE_TIME_GAME/
- 소스 저장소: https://github.com/youmjjang/MOVE_TIME_GAME

## 핵심 규칙
- WASD / 방향키를 누르는 동안 플레이어가 프레임 기반으로 부드럽게 이동합니다.
- 플레이어가 실제로 움직이는 동안에만 적과 남은 이동 시간이 함께 움직입니다.
- 가만히 있으면 세상도 멈춥니다.
- EXIT에 도착하면 성공, 적과 충돌하거나 이동 시간이 0이면 실패합니다.

## 조작
- WASD / 방향키: 이동
- Enter: 시작 / 다음 스테이지 / 실패 후 재시작 / 일시정지 해제
- P: 일시정지 / 재개
- R: 현재 게임 재시작

## 스테이지
1. FIRST TICK — 기본 규칙
2. GATE RUN — 큰 원형 적
3. CROSS SIGNAL — 가로·세로 교차
4. NARROW BEAT — 좁은 통로
5. DOUBLE SWEEP — 가로 이동 원형 적
6. MOVING DOORS — 원형 적 사이의 틈
7. RED CORRIDOR — 큰 적
8. CROSS GRID — 복합 교차
9. LAST HALL — 연속 원형 적 구간
10. TIME CORE — 최종 구역

모든 스테이지의 제한 이동 시간은 30초 이하입니다.

## 과제 카드 3 — 20회 난이도 비교
상단 `난이도 실험` 버튼을 누르면 동일한 고정 코스에서 비교하는 실험 모드가 열립니다.

- TEST A: 적 이동 속도 1.00×
- TEST B: 적 이동 속도 1.18×
- 바뀌는 값: **적 이동 속도 하나뿐**
- 고정 실험 코스, 제한시간, 플레이어 이동량, 벽, 적 수는 동일
- A 10회가 끝나면 자동으로 B 기록으로 넘어갑니다.
- `20회 기록 CSV 저장` 버튼으로 기록을 내려받을 수 있습니다.
- CSV에는 결과, 사용시간, 이동 입력 수, 실패 원인이 들어갑니다.

동일한 입력 경로 10개를 A와 B에 각각 적용한 결과 A는 3회, B는 5회 성공했습니다.
사용시간 중앙값은 A 3.00초, B 2.95초였고 적 충돌 실패는 A 7회, B 5회였습니다.
성공과 실패가 고르게 나타나고 충돌 실패가 덜 반복된 B의 `1.18×`를 최종 적 속도로 선택했습니다.
전체 20회 기록은 [`evidence/PLAYTEST_RESULTS.csv`](evidence/PLAYTEST_RESULTS.csv)에 있습니다.

## 저장과 손상 복구
브라우저 localStorage에 아래만 보존됩니다.
- 스테이지별 최고 기록
- 움직임 줄이기 설정
- 음소거 설정
- 난이도 실험 A/B 기록

현재 판의 위치, 남은 시간, 적 위치, 이동 횟수는 새 게임마다 초기화됩니다.

저장 JSON이 없거나 손상되었거나 예상 형식이 아니면 기본값으로 안전하게 복구합니다.
화면 아래 `저장 초기화` 버튼으로 직접 초기화할 수 있습니다.

## 효과 선택권
- 클리어: 초록 파티클/플래시
- 실패: 짧은 화면 흔들림

## 실행
압축을 풀고 `index.html`을 Chrome에서 열면 됩니다.


## 연속 입력 검사 메모
이동 이벤트 리스너는 한 번만 등록됩니다.
`keydown` 자동 반복은 별도 동작을 중복 생성하지 않고, 처음 눌린 상태만 1회 반영합니다.
실제 이동은 `requestAnimationFrame` 기반으로 처리해 프레임이 끊기지 않도록 했습니다.


## 적 디자인 통일
- Stage 1~10의 모든 적을 원형으로 통일했습니다.
- 네모/막대 적은 제거했습니다.
- 뒤 스테이지는 원형 적의 크기, 수, 속도, 가로/세로 이동 경로로 난이도를 올립니다.
- 기존의 부드러운 연속 이동 방식은 그대로 유지합니다.

변환된 막대형 적 수: 28


## Stage 6 맵 수정
- 두 번째와 네 번째 원형 적 위쪽에 빠져 있던 세로 벽을 추가했습니다.
- 모든 주요 세로 기둥이 위/아래 한 쌍으로 보이도록 통일했습니다.
- 적 주변에는 실제로 통과할 수 있는 틈을 남겼습니다.


## Stage 7~10 밸런스 수정
- Stage 7부터 좌우 교차 적을 메인 패턴으로 변경했습니다.
- Stage 7: 좌우 6 + 세로 1
- Stage 8: 좌우 7 + 세로 2
- Stage 9: 좌우 8 + 세로 1
- Stage 10: 좌우 9 + 세로 2
- 맵 양옆의 의미 없는 빈 공간을 줄이고, 벽을 안전지대/통로 역할로 재배치했습니다.
- 제한시간은 23 → 22 → 21 → 20초로 완만하게 상승하도록 조정했습니다.


## 음소거
상단 `음소거`를 켜면 성공/실패 효과음이 재생되지 않습니다.
효과음 재생 중 음소거를 켜도 즉시 중단합니다.
효과음은 Web Audio API로 브라우저 안에서 생성하며 외부 음원 파일이나 API를 사용하지 않습니다.
음소거 설정은 localStorage에 보존됩니다.
