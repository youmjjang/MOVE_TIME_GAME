# PC 경계 검사 결과

검사일: 2026-09-10

| 검사 | 결과 | 확인값 |
|---|---|---|
| 1366×768 | PASS | 가로 넘침 없음, 캔버스 좌우 86.5px~1264.5px로 화면 안에 표시 |
| 1920×1080 | PASS | 가로 넘침 없음, 캔버스 좌우 371px~1549px로 화면 안에 표시 |
| 1초 이내 동일 입력 10회 | PASS | `D` 입력 10회 뒤 이동 입력 표시값 10 |
| 창 크기 변경 | PASS | 두 해상도 전환 뒤 상태와 조작 유지 |
| 포커스 이탈 | PASS | 이동키 상태를 비우고 자동 일시정지하도록 구현 및 검사 |
| 일시정지 | PASS | 일시정지 중 게임 업데이트 중단, 재개 가능 |
| 10분 상당 연속 실행 | PASS | 브라우저 가상시간 600,000ms 진행 뒤 입력 가능 |
| 브라우저 콘솔 | PASS | 자동 검사와 최종 로컬 브라우저 검사 모두 오류 0건 |

게임 루프는 `requestAnimationFrame` 하나만 사용하며 반복 타이머를 누적 생성하지 않습니다.
